# weather-app
A simple weather app made using HTML, CSS and JavaScript.

This project fetches live weather data from the OpenWeatherMap API and displays the temperature of the entered city.

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- OpenWeatherMap API

## Future Improvements

- Add dark mode
- Add loading animation
